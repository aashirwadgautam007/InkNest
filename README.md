# InkNest

InkNest is a full-stack blogging web application where users can register, log in, create blogs, edit their posts, delete posts, and view blog details.

## 🚀 Live Demo

Frontend: https://inknest-frontend.onrender.com

Backend: https://inknest-backend-36m2.onrender.com

## ✨ Features

- User registration
- User login and logout
- Authentication using tokens
- Create blog posts
- Edit blog posts
- Delete blog posts
- View personal blogs
- View blog details
- Responsive design
- Single Page Application (SPA) routing
- Deployed frontend and backend

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Deployment
- Render
- GitHub
